운영 서버의 보관 국가·지역, 위탁/국외 처리 세부사항과 백업·접속 로그 보유 기간은 운영 설정 확인 전이므로 최종 고지가 확정되지 않았어요.

운영 및 문의

똑독(DDOKDOK) 운영팀이 서비스를 운영해요.
개인정보 문의와 열람·정정·삭제 요청은 team.ddokdok@gmail.com으로 보내 주세요.

대상 연령

만 13세부터 둘러볼 수 있어요.
가입·저장은 만 14세부터 이용할 수 있어요.
입력한 만 나이 숫자는 기기에서만 확인하며 서버에는 만 14세 이상이라는 본인의 확인 여부·확인 시각·안내 버전만 새로 저장해요.
이 절차는 신분증 등을 이용한 본인·연령 인증을 뜻하지 않아요.

처리하는 정보와 목적

정보목적
카카오 인증과 연결된 계정 식별 정보, 닉네임, 인증 토큰가입·로그인·계정 관리와 본인 확인.
선택한 프로필 사진, 독서 목표·성향 답변·유형·공개 설정프로필 표시와 맞춤 독서 제공.
선택한 책·진도·독서일·완독·찜·책갈피·형광펜·메모·문장·그림 및 적용 설정개인 독서 기록과 보관함의 저장·동기화.
포인트 적립·사용과 가상 문구 보유 내역미션·가상 문구 구매 및 잔액 관리.
게시글·댓글·연결한 책·공유 그림·좋아요·투표·공개 범위커뮤니티 게시와 상호작용.
규칙 동의 버전·시각, 신고자·대상 계정/콘텐츠 식별 정보·사유·설명·처리 상태, 차단 관계·운영자 처리/제재 기록커뮤니티 안전 관리·신고 검토·이용 제한과 이의신청 대응.

현재 앱은 Firebase나 Google 로그인·FCM을 연결하지 않았어요.
광고 ID·기기 고유 ID·연락처·위치를 읽는 수집 코드는 사용하지 않아요.
다만 연결 과정에서 서버가 받는 IP·HTTP 요청 정보와 서비스 로그의 실제 보유 범위는 운영 설정 확인 대상이에요.

저장과 외부 서비스

현재 회원 인증과 DB API는 Supabase에, SNS 인증은 카카오에 연결돼 있어요.
프로필 사진과 만든 그림도 DB에 이미지 문자열로 저장될 수 있어요.
외부 서비스의 실제 수탁·국외 처리 조건과 서버 지역은 출시 전 확인해 안내해요.
사용자가 다른 앱으로 공유하면 선택한 내용이 해당 앱으로 전달돼요.

보유와 삭제

회원정보·개인 기록·작성한 콘텐츠는 계정을 유지하는 동안 서비스 제공을 위해 저장해요.
내 글·댓글은 직접 삭제할 수 있고, 탈퇴 완료 시 계정에 연결된 개인 기록과 콘텐츠·신고·차단·제재 데이터를 삭제해요.
서버 파일은 Storage API로 삭제한 뒤 인증 계정을 삭제해요.
서버 처리가 완료되지 않으면 탈퇴 완료로 표시하지 않아요.

직접 저장하거나 외부에 공유한 사본과 서버 운영 백업/로그는 동일한 자동 삭제 범위가 아니에요.
백업·로그의 별도 보유 기간과 파기 절차는 출시 전 확인해요.

권리 행사

프로필 편집에서 정보를 바꾸고, 설정의 회원 탈퇴 또는 웹 삭제 요청을 이용할 수 있어요.
접근이 어렵거나 다른 권리를 행사하려면 운영팀으로 연락해 주세요.
비밀번호·인증번호는 보내지 마세요.

보호 조치

서버 API는 HTTPS로 연결하고 계정에 따른 조회·수정 권한을 서버에서 검사해요.
신고 목록과 운영 조치는 서버에 등록된 운영자만 사용할 수 있어요.
Android 앱의 자동 백업은 비활성화해요.
